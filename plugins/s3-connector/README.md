Houses the S3 protocol SDK PHP libraries and manages access keys. Required by other AWS plugins.

Description
--------

This plugin is required by other plugins, which uses its libraries and its settings to connect to DeSMan Object Storage Services. Currently, there is only one plugin that requires this plugin:

* [DeSMan Object Storage](http://www.inetu.net/)


Installation
-------

1. Use WordPress' built-in installer
2. A new DeSMan menu will appear in the side menu
